### Duplicate consolidation — planner + safe apply

`bin/sprawl_scan.py` gained a consolidation planner. Byte-identical is necessary
but not sufficient, so each identical family is classified:

- `SAFE` — extra copy is a stray outside the canonical tree → collapse
  (backup + pointer stub).
- `MIRROR` (multi-project), `CONFIG` (agent-tool dir), `SNAPSHOT`
  (`.dev-cockpit/workspaces`), `REVIEW` (cross-project) → **left for a human**.

2 REVIEW, 1 CONFIG, 3 SAFE**. Applied the 3 SAFE strays:

`Tribunal/~/tribunal/docs/WHITEPAPER_DRAFT.md` (→ `tribunal/docs/`). Backups

nothing was committed for them. 6 new tests (`test_sprawl_scan.py`).
